# PageTrace — Release (P026)

**Version:** 0.1.0 · **Spec:** v1.0.0 (frozen) · **License:** MIT
**Freeze commit:** `d0aa21f` (FIX-R1 code freeze; T001–T014 all PASS + FIX-R1 fixes — see `00_control/FIX_R1_FREEZE_REPORT.md` for the full freeze record)
**Release built:** 2026-11-17 (FIX-R1; release packaging on top of `d0aa21f`; exact release commit in the freeze report)

PageTrace checks whether a cited page number still points at the true
source page of a quotation after the quotation has travelled through a
PDF pipeline: **PDF truth → Extraction → Chunking → Indexing →
Display**. For each citation it reports a verdict, the fault type, and
the first stage where a provable difference appears. It never guesses a
page: uncertainty is reported as uncertainty, never converted to PASS.

## What it does NOT do

- **No OCR.** A quote that only exists as raster/image text is reported
  `FAIL_UNLOCATABLE` — this does *not* establish the quoted text is
  absent from the document.
- **No semantic fact-checking.** PageTrace verifies *page identity*
  (does the cited page match the page where the normalised quote was
  actually found?), not whether the quoted claim is true.
- **No claim about real systems.** S0 passing means the tool behaves
  correctly on the 48 frozen synthetic fixtures. It is not evidence
  that any real-world PDF pipeline has passed. Full boundary list:
  `docs/LIMITATIONS.md` inside the package.

## Known limitations carried into this release (not hidden)

- The Oracle's triple-span probe is a bounded subset of production's
  exhaustive search (P2-07, recorded in `docs/LIMITATIONS.md`).
- Production and the Oracle disagree on one `reason` string for
  out-of-range display values (`VALUE_OUT_OF_RANGE` vs
  `VALUE_BASIS_TYPE_MISMATCH`); the verdict agrees and `reason` is not
  an S0 parity field (P2-04, recorded).
- `fixtures build` is not implemented; the 48 fixtures are frozen
  T002 products (P2-10, recorded).
- One fixture-spec wording deviation (P2-11, FIXED by FIX-R1):
  `un-ext-12`'s pages were all text pages although spec §8.1 describes
  the UN class as image/blank pages. The generator now guarantees a
  non-text page for near-miss UN cases and `un-ext-09..12` were
  regenerated; all 12 UN cases now contain an image or blank page.
- The 13 P2 findings from the T012 independent review were all closed
  by T013 (10 fixed, 3 recorded); see
  `07_evidence/runtime_logs/T013_FIX_RECORD.md`.
